Rockford Homes

Real Estate Touring App

Developed in collaboration with Pixl3D, Rockford Homes uses a floor-plan customization engine made from scratch in Unity. Rockford Homes is a multi-million dollar community development company based in Columbus, Ohio.

Rockford Homes is a multi-platform home customization app available on the Apple App Store, Google Play Store, Microsoft Windows Store and as a WebGL app at the Rockford Homes website. Developed using Unity, the app is free to download and allows the user to choose options for a variety of floor plans. The user can then submit their choices to the Rockford Homes sales team with a single click using an in-house developed AWS backend. The user can also explore a virtual copy of their new community using Google satellite data and custom neighborhood modeling. SplenSoft handles the code, backend maintenance and UI programming, while Pixl3D handles client relations, visual renders and 3D modeling.

preform.io / be.FORE

digital art installation and portfolio website

be.FORE is a digital performance piece that uses Unity WebGL and MediaPipe machine learning. Using full-body and facial tracking via webcam, the user is displayed on-screen, becoming the art. Additionally, preform.io is the portfolio website for the artist in charge of the project, David Allen, and his team of collaborators.

In this project, SplenSoft was in charge of setting up the code and UI framework for be.Fore, as well as fully developing the logic and laying the groundwork for the preform.io website. Using the Unity engine, be.Fore, which can be experienced online, is a complex, multi-faceted work of art that utilizes Google's MediaPipe to transport the user's image to a surreal visual stage. Among the challenges of this project was conceptualizing the data flow between MediaPipe and Unity, which involves performance friendly serialization from the browser environment to multiple running binaries, and also developing a standalone version of the app that can be used offline. Later in the development, support was added for external stage effect controllers using a NodeJS-powered OSC and HTML server. The preform.io website project was a collaboration between an incredible design team and SplenSoft. Most of the work was bringing mocks to life using HTML, CSS and JavaScript programming, as well as creating a proprietary special effects renderer using WebGL and custom shaders.

SkateBud

skateboarding video game

SkateBud is a side-scrolling, pixel-art video game designed by Zach Moldof, a renowned musician and entrepreneur, and developed by SplenSoft. The game features a unique control scheme and ties into a larger brand, which includes skateboarding apparel, lessons and celebrity collaboration.

SkateBud is a unique side-scrolling game that abandons traditional scoring mechanics in favor of artistic expression and chill/psychedelic vibes. It features music from Zach Moldof, the game's brain and artistic director, as well as other nationally known artists. SkateBud as a brand is a west-coast-based skateboarding emporium that features heavily in the local skatepark scene via live events and community involvement. The game is currently available on the Apple App Store.

Roberto

brain and body wellness app

Roberto, a collaboration with the estate of famous Pittsburgh baseball player Roberto Clemente Jr., is a brain and body metric app that helps the user measure their memory and mind performance and wellbeing.

Roberto is a Unity app championed by RC21X, a Pittsburgh based software development firm that has provided brain health SAAS since the mid 2010s. On the Roberto website, you can learn more about the app and what it does. It's available on mobile devices via Google Play, Amazon and the Apple App Store. Roberto uses simple, entertaining memory and reaction games to score a user's overall brain health while providing a platform to track weight, sleep, fitness, and other body metrics. The back-end utilizes complex algorithms developed by world-renowned physicians. SplenSoft took over development of the app in 2019, modernizing the UI, improving the app's performance and ensuring a solid overal design while increasing data security. The app is used in Pittsburgh public schools to help students track their wellness and has been used by multiple prominent organizations to help individuals with brain injuries and disorders.
